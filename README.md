# 極光提示詞產生器 ✨

**Aura Prompt Generator** — 一款強大的隨機 AI 提示詞組合工具，支援多欄位管理、設定檔儲存、固定標籤，以及跨裝置便攜包同步。

🔗 **線上使用**：[https://3587sen-web.github.io/randomprompt/](https://3587sen-web.github.io/randomprompt/)

---

## 功能特色

- 🎯 **多欄位隨機組合** — 自訂欄位數量（2–99）、標題、內容，隨機抽選產生 Prompt
- 💾 **設定檔管理** — 儲存、載入、匯出、匯入多組設定檔
- 📌 **固定附加標籤** — 設定每次必定出現的關鍵字
- 📦 **便攜包同步** — 一鍵打包所有資料，在另一台電腦上完整還原
- 🌙 **深色霓虹風格 UI** — 玻璃擬態設計，支援拖曳排序

## 跨裝置使用說明

```
電腦 A → 點「📦 匯出便攜包」→ 下載 JSON 檔
電腦 B → 開啟同一個網址 → 點「📥 還原便攜包」→ 選取 JSON → 完成！
```

## 技術規格

- 資料存於瀏覽器 `localStorage`
