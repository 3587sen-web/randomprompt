# 極光提示詞產生器 ✨

**Aura Prompt Generator** — 一款強大的隨機 AI 提示詞組合工具，支援多欄位管理、設定檔儲存、固定標籤，以及跨裝置便攜包同步。

🔗 **線上使用**：[https://3587sen-web.github.io/randomprompt/](https://3587sen-web.github.io/randomprompt/)

---

## 功能特色

- 🎯 **多欄位隨機組合** — 自訂欄位數量（2–500）、標題、內容，隨機抽選產生 Prompt
- 🔮 **底部操作列** — 「隨機生成／複製」固定在畫面底部，捲到哪裡都按得到，還能預覽最新結果
- 💾 **設定檔管理** — 儲存、載入、複製、匯出多組設定檔
- 📌 **固定附加標籤** — 設定每次必定出現的關鍵字
- 🔒 **鎖定欄位值** — 喜歡某一欄抽到的結果，按 🔒 固定下來，其他欄繼續隨機
- 🔗 **共用素材庫** — 多個設定檔共用同一份素材，改一次全部同步
- 📦 **完整備份** — 一鍵打包所有資料，在另一台電腦上完整還原
- 🌙 **深色霓虹風格 UI** — 玻璃擬態設計，支援拖曳排序，手機也能操作

## 快速上手

1. 在「設定檔管理」選一個設定檔 → 按「📂 載入」（或從右上角「⋯ 更多」→「載入範例」）
2. 按畫面底部的「🔮 隨機生成」
3. 按「📋 複製」，貼到你的 AI 繪圖工具

每張欄位卡片右上角的「⋯」裡有：移動位置、複製／剪下／貼上欄位、插入新欄位、連結素材庫、刪除欄位。

## 調整生成順序

**卡片排第幾，生成時就排第幾**。越重要的關鍵字放越前面。

- **拖曳**：按住卡片左上的 ⠿ 拖到想要的位置（滑鼠、手指都可以）
- **選單**：卡片「⋯」→ ⏫ 移到最前面／⬆️ 上移／⬇️ 下移／⏬ 移到最後
- **輸入位置**：點卡片上的編號，直接輸入要移到第幾位
- **依分類一次排好**：「⚙️ 依分類排序」→ 設定每個分類的數字 → 按「依分類重新排序」（只排這一次，之後仍可自由調整）

結果區上方的「生成順序」會列出實際的先後，例如 `📌 開頭固定標籤 → 1 髮型 → 2 Background …`。
固定附加標籤設在「開頭」時會排在所有欄位前面；想讓某個欄位真正排第一，把固定標籤改到「結尾」或某欄之後。

## 素材庫：改一次，所有設定檔一起更新

例：「Nike球鞋」欄位從 100 款補到 500 款，10 個設定檔都要跟著更新。

**第一次設定（只做一次）**
1. 「🔗 素材庫 ▾」→「📚 管理素材庫」→「＋ 新增素材」，名稱取跟欄位標題一樣（例如「Nike球鞋」），貼上內容
2. 「🔗 素材庫 ▾」→「🪄 自動連結同名欄位」→ 範圍選「目前畫面＋所有已存的設定檔」→ 確認
   - 標題比對不分大小寫、全半形與空白（「Nike球鞋」＝「nike 球鞋」）
   - 內容跟素材相同的會預設勾選；內容不同的預設不勾，避免蓋掉你刻意做的版本

**之後每次**：只在素材庫改內容，所有連結的設定檔自動變成最新，不用再按任何按鈕。

**其他**
- 「🧩 從設定檔建立素材庫」：自動找出多個設定檔共用、內容一樣的欄位，一次建成素材並連好
- 素材庫每一項會顯示用在哪些設定檔
- 連結時，欄位原本的內容會保留成備份；解除連結可選擇還原。刪除素材時，內容會寫回所有用到它的設定檔，不會變空白

## 快捷鍵

## 備份與跨裝置使用

> ⚠️ 資料只存在**這台裝置的這個瀏覽器**裡。清除瀏覽器資料、換電腦或換瀏覽器都會看不到，請定期備份。頁面超過 14 天沒備份會提醒你。

```
電腦 A → 頁面最下方「備份與還原」→ 📦 下載完整備份 → 得到一個 JSON 檔
電腦 B → 開啟同一個網址 → 📥 從備份還原 → 選取 JSON → 完成！
```

- **完整備份**：所有欄位、設定檔、固定標籤、素材庫。換電腦用這個。
- **只有設定檔**：只匯出／匯入設定檔清單，適合分享給別人。匯入時預設是「合併」，不會刪掉你原本的設定檔。
