# 極光提示詞產生器 ✨

**Aura Prompt Generator** — 一款強大的隨機 AI 提示詞組合工具，支援多欄位管理、設定檔儲存、固定標籤，以及跨裝置便攜包同步。

🔗 **線上使用**：[https://3587sen-web.github.io/randomprompt/](https://3587sen-web.github.io/randomprompt/)

---

## 功能特色

- 🎯 **多欄位隨機組合** — 自訂欄位數量（2–500）、標題、內容，隨機抽選產生 Prompt
- 🔮 **底部操作列** — 「隨機生成／複製」固定在畫面底部，捲到哪裡都按得到，還能預覽最新結果
- 💾 **設定檔管理** — 儲存、載入、複製、匯出多組設定檔
- 📌 **固定附加標籤** — 設定每次必定出現的關鍵字
- 🔒 **鎖定欄位值** — 喜歡某一欄抽到的結果，按 🔒 固定下來，其他欄繼續隨機
- 🔗 **共用素材庫** — 多個設定檔共用同一份素材，改一次全部同步
- 📦 **完整備份** — 一鍵打包所有資料，在另一台電腦上完整還原
- 🌙 **深色霓虹風格 UI** — 玻璃擬態設計，支援拖曳排序，手機也能操作

## 快速上手

1. 在「設定檔管理」選一個設定檔 → 按「📂 載入」（或從右上角「⋯ 更多」→「載入範例」）
2. 按畫面底部的「🔮 隨機生成」
3. 按「📋 複製」，貼到你的 AI 繪圖工具

每張欄位卡片右上角的「⋯」裡有：複製／剪下／貼上欄位、插入新欄位、連結素材庫、刪除欄位。

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `Ctrl + Enter`（Mac：`⌘ + Enter`） | 隨機生成 |
| `Ctrl + Shift + Enter`（Mac：`⌘ + Shift + Enter`） | 複製全部結果 |
| `Esc` | 關閉選單 |

## 備份與跨裝置使用

> ⚠️ 資料只存在**這台裝置的這個瀏覽器**裡。清除瀏覽器資料、換電腦或換瀏覽器都會看不到，請定期備份。頁面超過 14 天沒備份會提醒你。

```
電腦 A → 頁面最下方「備份與還原」→ 📦 下載完整備份 → 得到一個 JSON 檔
電腦 B → 開啟同一個網址 → 📥 從備份還原 → 選取 JSON → 完成！
```

- **完整備份**：所有欄位、設定檔、固定標籤、素材庫。換電腦用這個。
- **只有設定檔**：只匯出／匯入設定檔清單，適合分享給別人。匯入時預設是「合併」，不會刪掉你原本的設定檔。
